# Electric Field Simulator

A Python-based simulation of electrostatic fields generated by multiple point charges. The project calculates the electric field using Coulomb's law and the superposition principle, then visualizes the field lines using NumPy and Matplotlib.

## Features

- Calculate the electric field generated by multiple point charges.
- Support positive and negative electric charges.
- Apply Coulomb's law and the superposition principle.
- Visualize electric field lines in two dimensions.
- Display charge positions, magnitudes, and polarities.
- Use color to represent the logarithm of the electric field magnitude.
- Customize charge magnitudes and coordinates.

## Future Improvements

- Calculate and visualize electric potential.
- Plot equipotential lines.
- Add interactive charge placement.
- Implement custom numerical integration methods for tracing field lines.
- Extend the simulation to continuous charge distributions.
- Compare numerical results with analytical solutions.
